# ARCHITECTURE.md

Static, prerendered single-page site. No backend, no analytics, no cookies.
Live at `https://stredevirad.github.io/portfolio/` (Vite `base: '/portfolio/'`).

## 1. Routes

| Route | What | File emitted by the build |
|---|---|---|
| `/` | Home: hero → manifesto → work reel → project index → experience → achievements → skills → contact | `dist/index.html` |
| `/work/<slug>` | Case study (aegis, kerala-flood-bench, cold-chain-handshake, deep-learning-tutor, grammar-tax) | `dist/work/<slug>/index.html` |
| `/resume` | Recruiter view as a page (same component as Recruiter mode); used to print the PDF | `dist/resume/index.html` |
| anything else | Not-found page | `dist/404.html` (GitHub Pages serves it with HTTP 404) |

Every known route is **prerendered to real HTML** at build time (React `renderToString` from an SSR build of
`src/entry-server.tsx`), with route-specific `<title>`, description, canonical and Open Graph tags. The client
hydrates with `hydrateRoot`. Deep links therefore return **HTTP 200 with content**, link previews work without
JS, and there is no hash routing and no 404-redirect trick. See ADR-002.

Client-side navigation uses a ~1 KB History-API router (`src/lib/router.tsx`), which strips/prepends the base.

## 2. Component tree

```
<App>                                   prefs context (theme, motion, sound, recruiter) + router
├── <SkipLink/>
├── <Preloader/>                        first visit only (sessionStorage), hands off into the hero name
├── <Cursor/>                           fine pointers only, contextual labels
├── <Header/>                           logo, nav (scramble on hover), <Toggles/>, Resume button, ⌘K hint
├── <main id="main">
│   ├── route "/"            <Home/>
│   │   ├── <Hero/>                     real HTML text (LCP) + <HeroCanvas/> (lazy three.js) or <HeroFallback/> (SVG)
│   │   ├── <Manifesto/>                "Evidence over guesses" + how I work (AI-assistance disclosure)
│   │   ├── <WorkReel/>                 pinned horizontal (desktop) / vertical (mobile) flagship cards → Flip to case study
│   │   ├── <ProjectIndex/>             all projects + <FilterChips/> (Flip re-layout)
│   │   ├── <Experience/>               self-drawing timeline
│   │   ├── <Achievements/>             counters (real values only) + <Marquee/>
│   │   ├── <Skills/>                   constellation; hover/focus a skill → highlight projects
│   │   └── <Contact/>                  magnetic CTA, copy-email toast, socials, live IST clock
│   ├── route "/work/:slug"  <CaseStudy/> problem → approach → <ArchitectureDiagram/> → stack → owned → results → links → prev/next
│   ├── route "/resume"      <Resume/>  plain single column, print CSS, PDF link
│   └── fallback             <NotFound/>
├── <Footer/>
├── <Toast/>
├── lazy <CommandPalette/>              Ctrl/⌘+K: jump, toggles, copy email, open GitHub, "ask" (abstaining fact search)
├── lazy <Terminal/>                    backtick
└── lazy <Unlock/>                      hidden easter egg (see CLAUDE.md only)
```

Recruiter mode = the `<Resume/>` component rendered in place of `<Home/>` (no WebGL, no cursor, no smooth scroll).

## 3. Content model (`src/content/*.ts`)

Typed data generated by hand from `docs/PORTFOLIO_FACTS.md`; components never hard-code facts.

```ts
type Source = { label: string; href?: string };          // provenance for every number
type Metric = { value: string; label: string; source: Source; note?: string };
type Project = {
  slug: string; title: string; tier: 'flagship' | 'lab' | 'archive';
  tags: ('ai' | 'backend' | 'android' | 'gis')[];
  oneLiner: string; whyHard: string;                      // card copy: what it is + why it's hard
  role: string; team?: string; status?: 'in-progress';
  award?: string; year?: string;
  stack: string[]; skills: SkillId[];                     // drives the skills constellation
  repo?: string; cover: CoverSpec; image?: ImageSpec;
  caseStudy?: { problem; approach; architecture: Diagram; owned: string[]; results: Metric[]; caveats: string[]; aiDisclosure: string };
};
```
Files: `site.ts` (identity, links, positioning), `projects.ts`, `experience.ts`, `achievements.ts`, `skills.ts`,
`terminal.ts`/`ask.ts` (derived Q&A index), `types.ts`.

## 4. Animation orchestration

- `src/lib/gsap.ts` registers ScrollTrigger, SplitText, Flip once (client only).
- Each section owns **one `gsap.context()`** created in `useGsap(scopeRef, fn, deps)` and reverted on unmount.
- `src/lib/smooth.ts` owns Lenis; Lenis drives `ScrollTrigger.update` via `gsap.ticker`. Disabled when motion is
  reduced, in recruiter mode, and on touch devices (native scroll is better there).
- `ScrollTrigger.refresh()` after `document.fonts.ready` and after hero/images load.
- Motion tokens (`src/design/tokens.ts`): durations `xs 0.2 / s 0.4 / m 0.7 / l 1.1 / xl 1.6 s`, eases
  `out: expo.out`, `inOut: power3.inOut`, `snap: back.out(1.4)`, stagger `chars 0.018 / lines 0.08 / cards 0.12`.
- Reduced motion (OS or toggle): no preloader, no Lenis, no pinning, no WebGL (static SVG), counters render final
  values, reveals are instant. Content is identical in both modes.

## 5. Performance strategy

Budget (enforced by `scripts/size.mjs` in CI): initial JS ≤ 200 KB gzip, excluding lazy chunks.

- Prerendered HTML: hero text is the LCP element and is painted from HTML; it is never hidden by `opacity:0`.
- The preloader overlays the already-painted hero and hands off to it, so it does not move the LCP element.
- three.js loads only after first paint + idle, only if WebGL is available, motion is full, the device passes the
  capability check (`hardwareConcurrency ≥ 4`, `deviceMemory ≥ 4` when exposed, no `saveData`) and a 0.5 s FPS probe.
- DPR capped at 1.5, render loop paused when the hero is offscreen (IntersectionObserver) or the tab is hidden.
- Fonts: 3 variable WOFF2 files (latin subset), display face preloaded, `font-display: swap`, metric-matched fallbacks.
- Images: AVIF + WebP with explicit width/height, `loading="lazy"` below the fold.
- Lazy chunks: case study, command palette, terminal, easter egg, three.js hero.

## 6. Build & deploy pipeline

```
npm ci
npm run build
  ├─ tsc --noEmit (strict)
  ├─ vite build                         → dist/ (client)
  ├─ vite build --ssr src/entry-server  → dist-ssr/
  └─ node scripts/postbuild.mjs
       ├─ prerender routes → dist/**/index.html + 404.html (title/meta/canonical/OG per route)
       ├─ sitemap.xml, robots.txt, llms.txt, resume.json
       ├─ OG image 1200×630 (Playwright screenshot of an HTML template from content data)
       └─ resume PDF (Playwright page.pdf() of /resume, real selectable text)
npx playwright test                     smoke, toggles, deep links, PDF, axe
→ actions/upload-pages-artifact → actions/deploy-pages
```
Workflow: `.github/workflows/deploy.yml` (push to `main`). Pages source: GitHub Actions.
