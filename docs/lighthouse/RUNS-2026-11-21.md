# Lighthouse runs — lazy scroll kit (2026-11-21)

Mobile, default (simulated) throttling. `bench` = Lighthouse's host benchmarkIndex; runs with a very different value
are not comparable (one production run at bench 903 scored home 71 and was discarded for that reason).

| build | runs (perf) | TBT ms (median) | LCP ms | Speed Index ms (median) |
|---|---|---|---|---|
| before — `01414c2` (scroll kit eager) | 98, 98, 98, 95, 98, 98 | 126 | ~910 | ~3,560 |
| lazy kit, primed on idle — `8b57d31` | 96, 99, 98 | 113 | 1,404 / 940 / 1,390 | 3,430 |
| lazy kit, primed after preloader — `d39352a` | 99, 98, 98 | 134 | 906 / 906 / 960 | 3,067 |

`8b57d31` regressed LCP in 2 of 3 runs (ScrollTrigger's registration forced a full-page layout while the hero
name was still settling); `d39352a` fixes that. Net vs. before: same Performance score and TBT within noise,
Speed Index ~14 % better, initial JS 161.3 → 129.1 KB gzip.
